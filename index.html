Project 01
AlertAura SOS
A women's personal safety application
GitHub

AlertAura SOS was born from a straightforward but urgent question: what's the fastest way to tell someone where you are when you feel unsafe? The answer I built is a single red button.

The app allows a user to register two trusted emergency contacts in advance. In a moment of distress, one tap triggers an automated SMS — powered by Twilio's messaging API — containing a Google Maps link with the user's precise real-time coordinates. No typing. No calls. No apps to navigate. Just one action.

The frontend is built in React with Tailwind CSS for a clean, distraction-free UI designed to function under stress. The backend is a lightweight Node.js server that handles contact storage, session management, and Twilio webhook delivery. Location data is captured via the browser's Geolocation API and never stored — it is sent once, in real time, and discarded.

What I learned: building for high-stakes moments demands ruthless simplicity. Every decision — from button size to the number of screens — was made with a frightened user in mind. This project taught me that good UX is not about aesthetics; it's about clarity under pressure.

Tech Stack
React Tailwind CSS Node.js Twilio API Google Maps API Geolocation API
Key Features
  • One-tap SMS with live location link
  • Two saved emergency contacts
  • No location data stored — privacy first
  • Fully responsive, mobile-first UI
  • Works on any modern browser, no install required

Project 02
SmartSkool Manager
A school management and communication platform
GitHub

SmartSkool Manager started with a frustration I observed firsthand: schools in Bangladesh rely heavily on paper notices, phone trees, and informal WhatsApp groups to manage communication between administrators, teachers, students, and parents. It's fragmented, inconsistent, and prone to information getting lost.

This platform brings that communication into a single, structured environment. Administrators can broadcast official notices and announcements to the entire school or specific classes. Teachers can send direct messages to students or parents. Students can follow one another, send connection requests, and build a network within the school — similar in feel to a professional network, but purpose-built for an academic context.

The notification system is a core piece of the architecture: every action — a new message, a friend request, an announcement — triggers a real-time notification to the relevant user. I paid particular attention to security and performance at scale, implementing input validation, rate limiting, and role-based access control to ensure that students cannot access administrative functions, and that private messages remain private.

What I learned: user management at scale is harder than it looks. Designing a permission system that is flexible enough for a school's many roles — admin, teacher, student, parent — while remaining simple to maintain pushed me to think carefully about data architecture before writing a single line of feature code.
